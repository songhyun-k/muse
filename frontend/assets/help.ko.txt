muse — Apple Music 터미널 플레이어

사용법: muse [옵션]
  --demo              계정 없이 UI 둘러보기 (재생·음량은 모의 동작)
  --language en|ko    화면 언어 (I로 변경)
  --theme porcelain|graphite|linen|midnight|ink
  --transparent / --opaque        터미널 / 테마 배경
  --hide-left / --show-left       탐색 패널 접기 / 펼치기
  --hide-right / --show-right     가사·큐 패널 접기 / 펼치기
  --plain-icons / --nerd-icons    일반 / Nerd Font 기호
  --reduced-motion / --motion     움직임 줄임 / 켬
  --fps 15|30|60      최대 화면 갱신 빈도 (기본 60)
  --256-color / --true-color      터미널 색상 범위
  --probe             Swift ↔ Rust 통신 확인
  --live-check        실제 Apple Music 검사 (권한 요청·짧은 재생 포함)
    --read-only       조회만 검사 (재생 조작 없음)
  --version           버전
  --help              도움말

--live-check 문구는 영어이며, 서비스 오류의 상세 내용은 원문 그대로 표시합니다.
추가 옵션은 --read-only만 지원하며, --language는 지원하지 않습니다.
